# 喝水小鎮 Water Town 💧🌱

一座**喝水就會成長**的 3D 可愛城市。每喝一次水，就用水壺的容量灌溉整座城市；喝得越規律，城市長出越多葉子、開花、結果。
A cute 3D city that grows every time you drink water.

這是一個可以直接在手機瀏覽器使用、也能「加入主畫面」變成 App 的 PWA（離線也能用，資料存在手機裡）。

## 在手機上使用

1. 用手機瀏覽器開啟網址（例如 GitHub Pages：`https://<帳號>.github.io/Water-Town/`）。
2. iPhone（Safari）：分享 → **加入主畫面**；Android（Chrome）：選單 → **安裝應用程式 / 加到主畫面**。
3. 之後從主畫面圖示開啟，就像一般 App 一樣全螢幕運作，離線也能用。

> 第一次部署 GitHub Pages：到 repo 的 **Settings → Pages → Source** 選 **GitHub Actions**，之後每次推到 `main` 都會自動部署（`.github/workflows/pages.yml`）。

本機測試：`npm start`（或 `python3 -m http.server 8080`），開啟 `http://localhost:8080`。
網址加上 `?debug` 會在設定裡出現「時間快轉一天」按鈕，方便測試日記與植物枯萎。

## 功能 Features

| # | 功能 | 說明 |
|---|------|------|
| 1 | 水壺 | 可新增 / 編輯 / 刪除水壺：名稱、容量、圖案、顏色。快速選擇「小 / 中 / 大水壺 = 500 / 700 / 1000 ml」，三個預設各有不同圖案。沒有水壺時按「喝水」會先引導新增水壺。 |
| 2 | 喝水 / 喝飲料 | 每 100 ml = 1 水源幣；喝飲料的水源幣與灌溉效果 ×½。每次都會記錄。 |
| 3 | 語言 | 繁體中文 / English 一鍵切換（右上角或設定）。 |
| 4 | 載入畫面 | 下雨澆灌小盆栽的動畫 + 22 則環保 / 健康的水知識（點一下換下一則）。 |
| 5 | 3D 介面 | Three.js 打造的漂浮小島立體城市（可拖曳、雙指縮放旋轉、按鈕旋轉視角），animate.css 與自製 CSS 立體按鈕、液體進度條、彈出動畫。 |
| 6 | 喝水日記 | 每天自動打分數（0–100 + 星星）並給回饋；隔天日記封面與早安彈窗會提醒昨天的狀況。月曆檢視每天紀錄。 |
| 7 | 圖鑑 | 植物圖鑑（25 種）與建築圖鑑（15 種），未發現的會顯示剪影與提示。 |
| 8 | 植物生死 | 三天都沒喝水 → 植物枯萎；每天有喝水（不論多少）→ 植物都會活著；喝很多永遠不會害死植物。快枯萎的植物頭上會出現紅色「!」驚嘆號。 |
| 9 | 擺放 | 小鎮從 **2×3 的小地塊 + 一格小水池**開始，累積喝水量越多就逐步開放更多土地，最後成為 10×10 的大島；每格是 1×1×1 方格；建築 1×1×1、1×1×2、2×2×1、2×2×2（不超過 2×2×2）；大樹佔 2×2；爬藤植物是貼在牆上的 1×1 或 1×2 貼圖。所有東西都能隨時移動、轉向、收進背包。 |
| 10 | 照相機 | 隨時拍下城市，產生拍立得風格照片，可儲存或分享。 |
| 11 | 太久沒喝水變黃色 | 超過設定時間（預設 3 小時，可選 2 / 3 / 4 小時或關閉）沒有喝水或飲料，App 左上角圖示、瀏覽器分頁圖示和手機狀態列會變成黃色的口渴小水滴，標題變成「💛 該喝水了」，城市上方出現黃色提醒按鈕；喝一口就變回藍色。支援的系統上（例如電腦版 Chrome / Edge 安裝的 App）還會在 App 圖示上顯示提醒標記。註：手機主畫面上的 App 圖示由系統固定，網頁 App 無法改變它的顏色。 |

## 遊戲規則 Rules

- **土地擴建**：小鎮一開始是 2×3 的小地塊，裡面只有一格小泉水。每次擴建多開放一排或一列土地，條件是「累積有效喝水量」：1 L → 3×3、2.5 L → 3×4、4.5 L → 4×4（河流出現）… 一直到 70 L 開放整座 10×10 的島（約一個月規律喝水）。下一次會開放的土地會以虛線格子預告，點一下可以看到還差多少 ml。土地開放後不會再關閉；舊版本的存檔會保留原本完整的 10×10 島。
- **灌溉**：每次喝水會灌溉城市裡所有活著的植物，並且每 100 ml（有效水量）讓一株植物多長一片葉子；每 500 ml 會冒出一株新芽。
- **城市濕度**（最近 24 小時的有效水量 ÷ 每日目標）決定會長出什麼：
  - 🌵 乾燥 (<40%)：仙人掌、仙人球、蘆薈、蒲公英…
  - 🌱 微濕 (40–80%)：幸運草、蕨類、松樹、多肉…
  - 🌿 滋潤 (80–120%)：藍莓、香蒲、睡蓮、牽牛花…
  - 🌊 豐沛 (>120%)：荷花、鳶尾花、垂柳、大橡樹、葡萄藤…
- **自然環境邏輯**：每種植物只會長在符合牠自然環境的地方——
  - 水生植物只在河裡或池塘（荷花只長在靜水的**池塘**）
  - 仙人掌只長在**遠離水邊**的乾燥土地（根會爛掉！），不會在河裡
  - 蕨類、香蒲、蘑菇需要**水邊濕潤**的草地（水井、噴水池也會讓周圍變濕潤）
  - 椰棗樹只長在**靠水的沙地**（綠洲）
  - 爬藤只長在**建築牆面**，而且被別的建築擋住的牆（沒有陽光）不能長；玻璃溫室的牆不能爬
  - 小木橋只能放在河上
- **建築會帶來植物**：風車 → 向日葵、溫室 → 鬱金香、蜂箱 → 蘋果樹、茶屋 → 櫻花樹、池塘 → 荷花；水塔讓水源幣 +10%。
- **成長**：每天的有效水量在目標的 90%–150% 是**完美區間**。植物累積「完美日」會變大，2 天開花、3–4 天結果（依品種）。
- **枯萎**：植物連續三個整天沒有喝水就會枯萎；第 2 天起頭上出現紅色「!」，最後一天變成「!!」。
- **商店**：用水源幣買建築、裝飾和神秘種子；種子長成什麼，取決於種下的地點和你的喝水量。

## 專案結構

```
index.html            App 外殼與載入畫面
css/app.css           立體可愛風格 UI
js/main.js            啟動（先顯示載入畫面，再載入 3D）
js/app.js             UI 控制器（喝水、擺放、日記、圖鑑、商店、設定、拍照）
js/game.js            純遊戲規則（可在 Node 測試）
js/data.js            植物 / 建築 / 水壺 / 小知識資料
js/models.js          程式產生的 3D 植物與建築模型
js/scene.js           Three.js 城市場景、手勢、特效、截圖
js/i18n.js            繁中 / 英文字串
sw.js, manifest       PWA 離線與安裝
vendor/               three.js r170、animate.css 4.1.1（MIT）
tests/game.test.mjs   規則測試：npm test
```
